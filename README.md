My Dear Data project is 'My Distractions'. This is interesting because I will be able to reflect on how frequently I am distracted and the main causes so I can eventually reduce them.

The columns I have separated my data into include what task I got distracted from, the activity I got distracted by, the duration, time and date. I have separated my distractions into categories that include phone, friends/family, food, sleep and other.

I started collecting data from 20/10/2026 and have data entries until 28/10/2026. As of now, I have logged 31 data items.
