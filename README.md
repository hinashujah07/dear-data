The topic for Dear Data project is 'My Distractions'. I have decided to collect data which will reflect how frequently I am distracted from my main task. This is an interesting topic because it will help me identify the most common causes of my distractions so I can eventually work on reducing them. 

The columns I have separated my data into include what task I got distracted from, which activity I got distracted by, the duration of each distraction, the time of day and the date. This will show patterns such as what activities I am usually distracted by, how long the distractions typically last and what time of the day I am most likely to be distracted. I have separated my distractions into categories that include phone, friends/family, food, sleep and other. Doing so will make it easy to display my data in the next part of this project.  

I am logging entries on Excel as it provides a clear, simple and organised format for storing data. However, this can be difficult to track as I don't always recognise when I am distracted or I may forget to record an entry. This could result in missing data, potentially delay my data collection and  make the data less accurate. I started collecting data from 20/10/2026 and have data entries until 28/10/2026. As of now, I have logged 31 data items. I have made multiple entries throughout the day and I plan to log data regularly, so I have enough time to test out visuals.
